Column Key

spp = Species of focus

Composition: Species of focus and Monoculture or Polyculture (M/P)

PlantS: Total number of unique species in the plot

S5: Parasite richness standardized to 5 random plants sampled within the plot (Desirability Variable)

percov: percent cover within the plot (Desirability Varaibility)

Div: Diversity, 1 = Polyculture, 0 = Monoculture

Res: Resource (Phosphorous, Nitrogen, Potassium) Treatment, 1 = PNK treatment applied, 0 = PNK treatment not applied (Environmental Axis)

Plot column represtents each unique plot through time: the number beginning it is the block number, the four letter code following that number is the species focused on in this plot, followed by its diversity classification (M or P), and finally the resource treatment (R = Treatment Applied, or O = Treatment not Applied)
